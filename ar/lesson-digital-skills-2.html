Using the internet safely

Digital Skills for Beginners - Lesson 2

The video for this lesson will be added soon. The full written lesson is below and you can start with it now.

Written lesson (transcript)

The internet is very useful, but we must treat it with care. The first rule is your password: make it long and never reuse it everywhere.

If a message asks for your bank details or a verification code, ignore it. Trustworthy services never ask for this information in a message.

Before paying or signing in, check the address is correct and starts with https. If you are unsure, ask someone you trust.

Key points

  • Use long, different passwords
  • Never share your banking details
  • Check the site address before entering data
